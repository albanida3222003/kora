Especificaciones del Sistema

Estructura de Datos y Modelado de Negocio

👤 Experiencia del Cliente

Captura eficiente de datos esenciales para evitar fricción en la compra:

  • Datos Personales: Nombre completo y número de celular.
  • Ubicación Exacta: Captura por GPS o selección directa en mapa.
  • Carrito Inteligente: Agrupación automática de ítems por restaurante.

🏪 Perfil del Restaurante

Gestión completa del establecimiento y su oferta:

  • Información Base: Nombre, WhatsApp, ubicación fija en mapa y horario semanal.
  • Identidad Visual: Espacio para Logotipo y Banner de Portada.
  • Catálogo Visual: Cada plato incluye imagen representativa.

🍽️ Modalidades de Productos (Platos)

  • Plato Estándar (Simple): Selección directa sin variantes (ej. Pollo Broaster, Bebida 1L).
  • Plato Configurable (Menús/Combos): Campos obligatorios de selección simple/múltiple antes de añadir al carrito (ej. Elección obligatoria de Entrada A o B, o Elección de Salsa para Alitas: Acevichada, Rebozada, etc.).
Reglas de Negocio

Cálculo Dinámico del Costo de Envío

Cálculo de tarifas basado en la distancia lineal real (coordenadas) entre la ubicación del cliente y el restaurante.

// Fórmula Algorítmica de Tarifa:
Distancia_KM = CalcularDistancia(Cliente_GPS, Restaurante_GPS);
Costo_Calculado = (Distancia_KM * S/ 2.00) + S/ 1.00;
Envío_Final = Math.max(S/ 5.00, Costo_Calculado);

🛍️ Manejo de Pedidos Multilocal (Múltiples Restaurantes)

Si el usuario realiza un pedido que incluye platos de diferentes locales en una misma compra:

  • El sistema aplica el cálculo tarifario de forma individual e independiente para cada local involucrado.
  • Costo Envío Total = (Tarifa Envío Local A) + (Tarifa Envío Local B)
  • Garantiza la rentabilidad del repartidor cubriendo la logística de recojo por separado.
Arquitectura y Herramientas

Tecnologías Seleccionadas y Justificación

FRONTEND WEB

HTML5 / CSS3 / JavaScript

  • Rendimiento Máximo: Carga ultra rápida en teléfonos móviles sin depender de descargas en App Stores.
  • Sin Mantenimiento Complejo: Código limpio, compatible con cualquier navegador moderno.
  • GitHub Pages: Alojamiento estático totalmente gratuito y seguro (SSL) con disponibilidad del 99.9%.
BACKEND & BASE DE DATOS

Supabase (Cloud Service)

  • Base de Datos Relacional: Almacenamiento seguro de platos, restaurantes, usuarios y pedidos.
  • Suscripción en Tiempo Real: Notificaciones inmediatas de nuevos pedidos sin recargar la pantalla.
  • Storage Integrado: Alojamiento optimizado de imágenes (Logos, Portadas y Fotos de Platos).
